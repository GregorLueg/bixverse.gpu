# Takes in a parametric UMAP and serialises it to raw bytes

**\[experimental\]** Serialises a trained parametric UMAP model to bytes
for saving the data.

## Usage

``` r
rs_serialise_parametric_umap(model)
```

## Arguments

- model:

  Robject. The trained parametric UMAP model to serialise.

## Value

The raw bytes of the model
