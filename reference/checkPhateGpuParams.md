# Check GPU PHATE params

Checkmate extension for the output of
[`params_phate_gpu()`](https://gregorlueg.github.io/bixverse.gpu/reference/params_phate_gpu.md).

## Usage

``` r
checkPhateGpuParams(x)
```

## Arguments

- x:

  The object to check.

## Value

`TRUE` if the check was successful, otherwise a checkmate-style error
string.
