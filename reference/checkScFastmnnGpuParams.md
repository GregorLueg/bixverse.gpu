# Check GPU fastMNN params

Checkmate extension for the output of
[`params_sc_fastmnn_gpu()`](https://gregorlueg.github.io/bixverse.gpu/reference/params_sc_fastmnn_gpu.md).

## Usage

``` r
checkScFastmnnGpuParams(x)
```

## Arguments

- x:

  The object to check.

## Value

`TRUE` if the check was successful, otherwise a checkmate-style error
string.
