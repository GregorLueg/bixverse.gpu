# Save a parametric UMAP as a qs2 file

Save a parametric UMAP as a qs2 file

## Usage

``` r
save_parametric_umap(model, path)
```

## Arguments

- model:

  `ParametricUmapModel` you want to save.

- path:

  String. The path to the file. Needs to end with `".qs"` file
  extension.

## Value

Saves the file to the provided path.
