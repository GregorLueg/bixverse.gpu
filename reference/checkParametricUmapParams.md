# Check parametric UMAP params

Checkmate extension for the output of
[`params_parametric_umap()`](https://gregorlueg.github.io/bixverse.gpu/reference/params_parametric_umap.md).

## Usage

``` r
checkParametricUmapParams(x)
```

## Arguments

- x:

  The object to check.

## Value

`TRUE` if the check was successful, otherwise a checkmate-style error
string.
