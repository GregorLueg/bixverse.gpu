# Check Harmony v2 GPU params

Checkmate extension for the output of
[`params_sc_harmony_v2_gpu()`](https://gregorlueg.github.io/bixverse.gpu/reference/params_sc_harmony_v2_gpu.md).

## Usage

``` r
checkScHarmonyV2GpuParams(x)
```

## Arguments

- x:

  The object to check.

## Value

`TRUE` if the check was successful, otherwise a checkmate-style error
string.
